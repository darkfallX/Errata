# Accessing the code frequency graph

## Step 2: Under your repository name, click Insights

Under your repository name, click Insights.
Verify that the repository's Insights page is visible.

## Step 3: In the left sidebar, click Code frequency

In the left sidebar, click Code frequency.
Verify that a code frequency graph of additions and deletions is visible.
