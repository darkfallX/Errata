# Using the activity view to see changes to a repository

## Step 2: On the main page of the repository, to the right of the list of files, click Activity

On the main page of the repository, to the right of the list of files, click Activity.
Verify that the repository's activity view, listing pushes and merges, is visible.

## Step 3: To filter by activity type, select the All activity dropdown menu, then click an activity type

To filter by activity type, select the All activity dropdown menu, then click an activity type.
Verify that a menu of activity types is open.
