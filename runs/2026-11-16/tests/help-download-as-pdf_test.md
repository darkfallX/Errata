# Help:Download as PDF

## Step 1: Open the Tools drop-down menu in the top navigation bar, below the page name

Open the Tools drop-down menu in the top navigation bar, below the page name.
Verify that the Tools menu is open, showing page tools.

## Step 2: In the Print/export section, select "Download as PDF"

In the Print/export section, select "Download as PDF".
Verify that a page offering to download the article as a PDF is shown.
