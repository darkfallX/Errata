# Viewing the line-by-line revision history for a file

## Step 2: Above the file content, click Blame

Above the file content, click Blame.
Verify that a line-by-line blame view, with code grouped by commit, is visible.

## Step 3: To return to the raw code view, above the file content, click Code

To return to the raw code view, above the file content, click Code.
Verify that the file's code view is shown again.

## Step 4: Click Readme.md

Click Readme.md.
Verify that the Markdown file is shown with formatting applied.
