# Viewing branches in your repository

## Step 2: From the repository's main page, click 23 Branches

From the repository's main page, click 23 Branches.
Verify that the repository's branches page is visible.

## Step 3: Active branches: The Active view shows all branches (excluding the default branch) that anyone has committed to within the last three months, ordered by the branches with the most recent commits first

Active branches: The Active view shows all branches (excluding the default branch) that anyone has committed to within the last three months, ordered by the branches with the most recent commits first.
Verify that the Active view of branches is shown.

## Step 4: All branches: The All view shows the default branch, followed by all other branches ordered by the branches with the most recent commits first

All branches: The All view shows the default branch, followed by all other branches ordered by the branches with the most recent commits first.
Verify that the All view of branches is shown, starting with the default branch.
